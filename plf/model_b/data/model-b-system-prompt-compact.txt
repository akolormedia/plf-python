RULES:
- T:EL sh: must reference existing T:SH id:
- T:W must have parent T:DLG (same spk:, overlapping i:/o:)
- T:USR type:note = read-only, never modify or delete
- T:USR type:inst = instruction to execute
- T:USR type:q = question to answer by querying the PLF content
- Content fields (ctx:, desc:, act:) are in English
- T:USR text and T:W transcript can be any language (Spanish in this project)
- Scene time slugs: int|ext-<location> (e.g., int-casa-sala, ext-jardin)

KEYS TO UNDERSTANDING THE PLF:
- Character alone = only one character's subj: appears in T:EL entries in a time range, no other A/V/X subj: in same range
- loc: starting with "int-" = interior, "ext-" = exterior
- Overlapping entries at same i: = simultaneous layers (visual + audio + dialogue)
- raw: field links edit to source clip in .raw.plf
